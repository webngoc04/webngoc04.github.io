# KeiChan's Personal Website & Tech Blog

Personal website and tech blog of KeiChan built with Next.js, React, Tailwind CSS, and Markdown.

## 🚀 Quick Start

```bash
npm run dev     # Start development server at http://localhost:3000
npm run build   # Build static export to out/
npm run lint    # Run ESLint check
```

## 🛠️ Deployment

This project is deployed to GitHub Pages using GitHub Actions (`.github/workflows/deploy.yml`).

> **Note for GitHub Pages Configuration:**  
> Go to **GitHub Repository Settings → Pages → Build and deployment → Source** and select **GitHub Actions**.
